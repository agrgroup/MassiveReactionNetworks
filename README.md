This repository contains the computational workflows, machine-learning models, reaction datasets, and automated reaction-enumeration tools developed for the study:

> **Data-driven massive reaction networks reveal mechanistic pathways underlying catalytic CO2 hydrogenation**

The work combines density functional theory (DFT) calculations, machine learning (ML), Automated Reaction Enumeration (ARE), Elementary Reaction Identification (ERI), and kinetic modeling to systematically investigate complex reaction networks underlying CO2 hydrogenation on copper.

## Overview

Heterogeneous catalytic pathways for clean energy conversion can involve thousands of elementary reactions, while conventional kinetic models typically consider only a small subset of possible pathways.

In this work, we develop a data-driven framework to construct and analyze large reaction networks for catalytic CO2 hydrogenation on copper.

The workflow combines:

* Extensive density functional theory (DFT) calculations
* Machine-learning-based activation-energy prediction
* Automated Reaction Enumeration (ARE)
* Elementary Reaction Identification (ERI)
* Automated construction of large reaction networks
* Kinetic modeling
* Experimental measurements of CO2 conversion and product formation

This approach reduces human bias in reaction-pathway selection and enables systematic exploration of reaction mechanisms containing thousands of elementary reactions.

The study constructs a dataset containing **152 elementary CO2 reduction reactions** and uses automated reaction enumeration to generate a network containing **9,389 elementary reactions**.

The resulting large reaction network predicts substantially higher CO2 conversion rates and reproduces experimental trends for methanol and CO production. The analysis further identifies inter-species hydrogen transfer and hydrogenation by molecular H2 as important mechanistic features.

## 1. Automated Reaction Enumeration (ARE)

The Automated Reaction Enumeration (ARE) module systematically generates possible elementary reactions from a set of adsorbed intermediates.

### Input

```text
ads species (ARE input file).xlsx
```

This file contains the adsorbed intermediates supplied to the ARE framework.

### Main Notebook

```text
Automated Reaction Enumeration.ipynb
```

This notebook implements the automated reaction-enumeration procedure and generates candidate elementary reactions based on the supplied intermediates.

### Output

```text
ARE Ouput (ERI Input).csv
```

The output contains the reactions generated by ARE, including the corresponding reactants and products. This file is used as input for the subsequent Elementary Reaction Identifier (ERI) workflow.

### Workflow

```text
Adsorbed intermediates
        |
        v
Automated Reaction Enumeration
        |
        v
Candidate elementary reactions
        |
        v
ARE Ouput (ERI Input).csv
```

## 2. Elementary Reaction Identifier (ERI)

The Elementary Reaction Identifier (ERI) framework identifies chemically meaningful elementary reaction classes from the large set of reactions generated by ARE.

### Input

```text
ARE Ouput (ERI Input).csv
```

### Benchmark Dataset

```text
Benchmark_elementary_reactions.csv
```

This CSV file contains manually labeled reactions used to benchmark and validate the ERI framework.

### Main Notebook

```text
Elementary_Reaction_Identifier.ipynb
```

This notebook implements the ERI workflow for identifying and classifying elementary reactions from the enumerated reaction space.

### Workflow

```text
ARE-generated reactions
        |
        v
Elementary Reaction Identifier
        |
        v
Identified elementary reaction classes
        |
        v
Reaction dataset for further analysis
```

## 3. Machine Learning (ML)

The `ML` directory contains the machine-learning workflows used for activation-energy prediction.

The notebooks include feature engineering, hyperparameter optimization, model selection, cross-validation, and prediction.

### `Ea.ipynb`

This notebook implements the machine-learning workflow for the AE-RE model, including:

* Feature engineering
* Model training
* Bayesian hyperparameter optimization
* Model selection
* Activation-energy prediction

### `Ga.ipynb`

This notebook implements the corresponding workflow for the AFE-RFE model, including:

* Feature engineering
* Hyperparameter optimization
* Model selection
* Activation-energy prediction

### `LOOCV.ipynb`

This notebook implements Leave-One-Out Cross-Validation (LOOCV) for the AE-RE model.

In LOOCV, each reaction is iteratively used as a test example while the remaining reactions are used for model training.

### `kfCV.ipynb`

This notebook implements k-Fold Cross-Validation for the AFE-RFE model.

The dataset is divided into `k` subsets, with each subset used as a validation set while the remaining subsets are used for training.

## Key Results

The methodology developed in this work enables reaction-network exploration at a scale that is difficult to achieve using conventional manually constructed mechanisms.

The main results include:

* A dataset containing **152 elementary CO2 reduction reactions**
* Automated enumeration of **9,389 elementary reactions**
* Demonstration that reaction networks containing only approximately 100 reactions can be insufficient to capture experimentally observed behavior
* Prediction of substantially higher CO2 conversion rates using the larger reaction network
* Reproduction of experimental trends for methanol and CO production
* Identification of inter-species hydrogen transfer as an important reaction pathway
* Identification of hydrogenation by molecular H2 as a critical mechanistic feature
* Data-driven discovery of mechanistic pathways that were subsequently validated
