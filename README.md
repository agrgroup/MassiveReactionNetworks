# Demystifying catalytic CO<sub>2</sub> reduction pathways with thousands of elementary reactions via mechanism discovery and machine-learned kinetic barriers

**Abstract**: <br>
Heterogeneous catalytic pathways involve thousands of elementary steps, forming an
 intricate web of chemical reactions, but most first-principles kinetic models involve only
 a few dozen elementary steps. Here, we combine extensive quantum-mechanical cal
culations of reaction thermodynamics/kinetics, machine-learning models for activation
 barrier prediction, and methods for automated reaction enumeration and elementary re
action identification. Thereby, we devise an approach that enables automated microki
netic modeling (MKM) of CO<sub>2</sub> reduction pathways on copper with an unprecedented
 9389 elementary reactions. We validate our computational outcomes with experimen
tal observations. The ensuing results follow experimental trends of methanol and CO
 production rates, contrary to the conclusions of MKM based on a smaller subset of
 manually curated reactions. Considering hundred-plus C1-C4 compounds, our auto
mated approach unravels intermolecular hydrogen-hopping reactions to be the key to
 accurately simulating the CO<sub>2</sub> reduction pathway. We also establish the importance
 of CH<sub>3</sub>CHO in forming longer-chain hydrocarbons. Overall, the proposed strategy to
 comprehensively model complex catalytic pathways will significantly advance compu
tational catalysis research and carbon conversion processes.

This project is organized into multiple folders, each containing relevant notebooks and data files for various machine learning models and frameworks. Below is an overview of the directory structure, including descriptions of each file and its purpose.

## Directory Structure:
### Automated Reaction Enumeration (ARE):
Input: ads species(ARE input file).xlsx <br>
Output: ARE Ouput (ERI Input).csv

#### Automated Reaction Enumeration.ipynb
This Jupyter Notebook serves as the core of the Automated Reaction Enumeration (ARE) tool. It contains the code necessary to systematically enumerate all possible chemical reactions based on a set of provided intermediates.

#### ads species(ARE input file)
The "ads species" file acts as the input for the ARE tool, containing information about the intermediates involved in the reaction processes. 

#### ARE Ouput (ERI Input).csv:
The output generated by the ARE tool is saved in a CSV format, titled "ARE Output (ERI Input).csv." This file compiles all the reactions generated during the enumeration process, including details such as reactants, and products involved. This structured output is designed for easy integration with subsequent tools or workflows, particularly for use in Elementary Reaction Identifier (ERI) systems, facilitating further analysis.

### ERI: 
Input: ARE Ouput (ERI Input).csv <br>
Output: 

#### Benchmark_elementary_reactions.csv:
This CSV file serves as a critical resource, containing manually labeled reactions that are used to validate the performance of the ERI framework. Including benchmark data is crucial for assessing the accuracy and reliability of the elementary reaction identification system.

#### Elementary_Reaction_Identifier.ipynb:
The Jupyter Notebook provided implements the core functionalities of the ERI framework. 

### ML: 

#### Ea.ipynb:
This notebook implements feature engineering, hyperparameter tuning, model selection, and prediction specifically for the AE-RE model. It provides a comprehensive approach to optimizing the model's performance using Bayesian-based hyperparameter optimizer.

#### Ga.ipynb:
Similar to Ea.ipynb, this notebook focuses on the AFE-RFE model. It covers feature engineering, hyperparameter tuning, model selection, and prediction.

#### LOOCV.ipynb:
This notebook implements Leave One Out Cross-validation (LOOCV) for the AE-RE model. LOOCV is a robust method for assessing model performance by using each data point as a test set while training on the remaining data.

#### kfCV.ipynb:
This notebook implements k-Fold Cross-validation for the AFE-RFE model. k-Fold CV is a widely used technique that helps ensure the model's generalizability by dividing the dataset into k subsets.

Feel free to explore each notebook for detailed implementations and methodologies!
